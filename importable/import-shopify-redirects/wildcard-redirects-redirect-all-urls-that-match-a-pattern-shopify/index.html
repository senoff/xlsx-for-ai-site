Shopify URL redirects — no wildcard matching

Wildcard redirects — redirect all URLs that match a pattern (Shopify limitation)

You want everything under an old path to forward to one new place, in a single rule. Shopify's built-in redirects don't support that — every "Redirect from" is an exact, literal path, not a pattern or a wildcard. Here's what that means for a bulk URL change, and how to still get it done from a spreadsheet.

import-shopify-redirects · xlsx-for-ai

Why there's no wildcard option

Shopify's URL Redirects feature — in the admin UI and in its CSV import — treats every "Redirect from" value as a literal string to match against the incoming request path. There's no support for /old-blog/*, regular expressions, or prefix matching that would catch every URL under a given path in one rule. This is a genuine platform limitation, not a setup mistake: you can't configure your way around it within Shopify's native tool.

What this means for a bulk URL change

If you're retiring an entire old blog, a discontinued collection structure, or a whole subfolder of pages, you can't write one rule and be done. Each individual old URL that should redirect needs its own row, with its own specific destination — even if every one of them is going to the same new landing page. For a few dozen URLs this is tedious by hand; for a few hundred, it's the difference between a spreadsheet job and a manual one.

How to build the list without doing it one by one

Pull the full list of old URLs — from an old sitemap, a crawl export, or Google Search Console's list of URLs that now 404 — into one column, and put the single destination URL in a second column for every row. That's exactly the shape Shopify's redirect import expects: one "Redirect from" / "Redirect to" pair per row, however many old URLs are mapping to the same new page.

If you truly need pattern matching

A handful of Shopify apps add prefix or wildcard redirect rules on top of the platform for cases where the URL structure is genuinely unpredictable (user-generated paths, for example). For most store migrations, though, the URL list is finite and knowable — upload it above and it'll be formatted into the row-per-URL shape Shopify's importer needs.
