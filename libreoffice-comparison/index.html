Recalculation results compared with LibreOffice.

One measured run on 2026-10-06, reproducible with one command. Every number and every row on this page comes from that run.

What was measured

The reference is a set of test formulas kept in the server repository. Each has a formula, input cells, an expected result and a citation to the file-format standard (ECMA-376 Part 1 §18.17) and the published function reference. Each formula was written into an .xlsx workbook with no stored result, recalculated by each engine, and the result compared with the expected one.

  • LibreOffice: LibreOffice 26.2.4.2, run headless, set to recalculate on load. A control workbook with wrong stored values confirmed that it recalculates.
  • Ours: the xlsx-for-ai recalculation engine at server commit 6da3c9188c72.
  • Test formulas found: 1010. Run: 847. Not run: 163, because the citation is not the file-format standard or the expected value is a placeholder.

In 86 cases across 53 functions, xlsx-for-ai matched the expected result and LibreOffice did not. Each was re-run on its own and read back a second way before being listed. In 12 cases LibreOffice matched and xlsx-for-ai did not: these are the matrix functions MDETERM, MINVERSE, MMULT and MUNIT, which xlsx-for-ai reported as not supported in this test setup.

Limits of this comparison

  • The test formulas were written and certified against the xlsx-for-ai engine, so its matches are expected and are not independent evidence. The independent part is LibreOffice against the cited results.
  • LibreOffice writes numbers with 15 significant digits when run headless, so a difference smaller than that cannot be seen here in either direction.
  • The set is the repository’s test formulas. It is not every function and not a random sample. A function with no test formula has no measurement.
  • One LibreOffice version on one operating system was measured. Other versions or load settings may differ.
  • COUNTUNIQUE is a Google Sheets function, so its two cases are left out of the table and the counts in the sentence above the table; they are still in the outcome counts.
  • Some citations in the test set also record a probe of another engine alongside the standard; the expected values themselves are the cited ones.

The method, the per-case data and the command to repeat the run are in the server repository under docs/libreoffice-comparison/ and scripts/libreoffice-compare/.
