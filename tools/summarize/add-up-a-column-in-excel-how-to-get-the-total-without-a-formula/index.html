The tools this page runs

Your agent calls xlsx_describe to profile each sheet and column, and xlsx_read to pull the underlying values it summarizes from.

  • xlsx_describe reports tabs, columns, and value ranges.
  • xlsx_read returns the data itself so the summary is grounded in real values.
