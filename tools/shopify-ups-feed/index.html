Export your orders from Shopify, upload the CSV, and get back a WorldShip batch import file — one row per order, ready to import and print labels. Set your package defaults if you like, or leave them blank; any order without a shippable address is listed for you rather than silently dropped.

What you upload

A Shopify orders export — not products. In your Shopify admin go to Orders → Export and choose the plain CSV. It has one row per order line with the shipping name, company, address, city, and country this tool turns into a shipment.

Why the package defaults

A Shopify order records what was bought and where it's going — but not how you'll box it. UPS needs a weight, box size, and service level for every shipment, so this tool fills those with sensible defaults (1 lb, 12×9×3 in, service 3DS, residential). Change any of them above to match how you actually ship; leave the rest blank.

What you get back

A UPS WorldShip batch import CSV with the columns WorldShip maps on import — Company or Name, Attention, Address, City, State, Postal Code, Country, plus your package and service defaults. In WorldShip, use Import/Export → Batch Import and point it at this file.

Business and residential addresses

When an order has both a company and a contact name, the company becomes the ship-to name and the person becomes the Attention line — so a B2B shipment isn't addressed to a person at a loading dock. Orders missing a usable destination are excluded and listed, never invented.

How it works

The page runs the same conversion your AI agent would call through our tools. It reads your export in memory and never stores it — your original CSV is untouched; you download a new import file, so nothing is ever lost.
