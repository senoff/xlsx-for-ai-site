Support

Need help with xlsx-for-ai? Email support@xlsx-for-ai.dev. A person reads every message.

What to include

  • What you asked the tool to do, in a sentence or two.
  • The tool name (for example xlsx_check or xlsx_eval) and the app you used it from.
  • The time you tried it, with your time zone, and the exact error text you saw.
  • Please do not attach a confidential workbook. A small example that shows the same problem is enough.

Before you write

  • If a tool says a function is not supported, that is reported as it is: xlsx-for-ai says so instead of guessing a value.
  • If a download link has stopped working, ask for the file again. Links expire after 60 minutes.
  • How files and data are handled is described on the privacy page, and the rules for using the service are on the terms page.
