Shopify product import — handle-matched updates

"Updating existing products isn't working — my changes didn't save" — handle-matched update not applying

You re-uploaded the CSV with your edits, Shopify said the import finished, and the store still shows the old values. Shopify update-imports match rows to existing products by the Handle column, and nothing else — not title, not SKU. If the handle in your file doesn't match the live product's handle exactly, your edits land on nothing. Drop your file in below to see which handles actually match.

What Shopify actually matches on

Product import updates work by comparing the Handle column in your CSV against the handle already on your store — the exact text that appears at the end of a product's URL, like /products/blue-mug. It is the only field the matcher uses. Title changes don't help it find the right product; SKU doesn't help either, unless you're specifically running a variant-level update by SKU through a different flow. If the Handle column is blank, wrong, or doesn't correspond to a real product, Shopify has no way to know which product you meant to edit.

How this handle mismatch actually happens

The most common cause is building the update file by hand instead of exporting it: someone types blue-mug as a handle because that's what the product is called, when the real handle on the store is blue-mug-14oz or blue-mug-1 (Shopify appends a number automatically if a handle was already taken when the product was created). A close second is editing a handle's capitalization or hyphenation slightly during a "cleanup" pass in Excel, not realizing the handle itself is the identity key, not just cosmetic text.

What happens to the row when it doesn't match

Depending on which columns are filled in, an unmatched Handle either creates a brand-new product (now you have a duplicate sitting in Drafts or Active, and the original is untouched) or gets skipped if required fields like price are missing on that row. Either outcome reports as part of a "successful" import — Shopify counted the row, it just didn't apply it where you expected.

How to fix it

Always start an update file from a fresh Export of your current products (Products → Export → selected products), edit the values you actually want to change, and leave the Handle column exactly as exported. Upload your file above and the checker will show you which handles in your file don't correspond to anything currently live on the store, before you upload to Shopify itself.
