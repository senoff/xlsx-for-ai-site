Percentages turned into decimals in my CSV — 50% shows as 0.5

50% became 0.5 in your CSV export? That's the actual stored value — Excel percentages are always stored as the decimal fraction, with the % sign being pure display formatting CSV can't carry. Here's what that means for your export

convert-excel-to-csv · xlsx-for-ai

50% and 0.5 aren't two different numbers — they're the same one

When you type 50% into a cell, Excel stores 0.5 and switches the cell's number format to Percentage, which is responsible for both multiplying the displayed figure by 100 and adding the percent sign on screen. The 0.5 has been the real, underlying value the entire time you were looking at 50% — the percentage display was always a formatting trick layered on top of it, never a separate stored figure.

Why the CSV shows the real stored value

Because CSV carries no formatting information whatsoever, any export process can only write out the actual value in the cell. Since that value has always been 0.5, that's exactly what lands in the CSV — the percent sign and the times-100 display simply have nowhere to go in a plain-text format, so they're left behind along with every other formatting instruction.

If the destination system needs a whole-number percent

Add a helper column with =A2*100 if the receiving system expects 50 rather than 0.5, or =TEXT(A2,"0%") if it actually needs the literal percent character as part of a text value, and export that helper column instead of the original. Check what the destination, whether it's a database import, an ad platform, or another spreadsheet, actually expects for a percent field before choosing between these, since conventions genuinely differ from one system to the next.
