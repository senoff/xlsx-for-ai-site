Collections and navigation are two separate systems

Shopify Navigation Menu vs. Collections — Why Don't My Collections Show on the Site?

You bulk-created or imported a batch of collections, checked the admin, and they're all there. But click around the actual storefront and none of them show up anywhere. They aren't broken — they're just not linked to. The free checker below maps your spreadsheet to a clean collections import; it won't wire up navigation for you, but knowing this distinction up front saves the confused re-import.

What you'll see

Every collection you created shows up in Shopify admin under Products → Collections. Each one has products in it, a description, an image if you added one. You can even open a collection directly by typing its URL — /collections/summer-sale, for example — and the page renders. But a customer browsing your site normally, clicking through the header or footer menu, never encounters it. It's as if the collection doesn't exist, even though every part of it works.

The root cause: creation and linking are unrelated steps

Shopify has no native CSV import for collections — building many at once is typically done through the Admin API, a bulk-editor workaround, or by creating them one at a time by hand. Whichever method you used, what it does is create the collection record: a handle, a title, a rule set or manual product list, and a page that Shopify serves automatically at /collections/<handle>. That page also gets picked up by Shopify's sitemap, so search engines can find it.

None of that touches your store's Navigation menus. The header menu, footer menu, and any dropdown submenus are a completely separate object in Shopify — a list of menu items you build manually under Online Store → Navigation, where each item is a link you choose to add. Creating a collection does not create a corresponding menu item, no matter how the collection was created or how many were created at once. This is true whether you added one collection by hand or bulk-created fifty from a spreadsheet-driven workflow — the linking step is identical either way, and it's always manual.

Why this is easy to miss after a bulk import

When you create one collection by hand in the admin UI, you're usually in the same mental flow as adding it to a menu, so the two steps don't feel disconnected. When fifty collections come out of a bulk process in one pass, there's no equivalent prompt reminding you to go add fifty menu items — so the collections finish "successfully" and the site looks unchanged, because from a browsing customer's perspective, it is unchanged.

How to fix it

Go to Online Store → Navigation, open the menu you want the collection to appear in (typically "Main menu" or "Footer"), and add a menu item that links to the collection — either as a top-level link or nested under a dropdown. Do this for each collection you want customers to be able to browse to. To verify, don't just visit the direct URL; click through the actual live menu on your storefront the way a customer would, since that's the only way to confirm the link is really there.
