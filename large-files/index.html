Large files.

Every file has a size limit for its type. The limits are the same for everyone, and no plan raises them. Plans are counted in files, never in size.

The limits

  • .xlsx: 100 MB
  • .csv: 200 MB
  • .xls: 100 MB
  • .xlsb: 10 MB
  • Any other type: 10 MB

The browser tools on this site accept files up to 10 MB, which is a choice made on those pages and is lower than the service’s own limits above. For a bigger file, use the API or the assistant connector instead (see the developers page).

If your file is over its limit

  • Split it. Save each sheet, or each block of rows, as its own workbook, and run them one at a time.
  • Convert it. A .csv takes up to 200 MB, twice what an .xlsx takes. Saving a large workbook as .csv, one sheet per file, often brings it under the limit. An .xlsb over 10 MB can be saved as .xlsx or .csv.
  • Trim it. Delete unused rows and columns, embedded images and old pivot caches, then save again.

Still stuck?

If none of that works for you, write to support@xlsx-for-ai.dev with the file type, its size and what you are trying to do, and we will reply with what we can do.
