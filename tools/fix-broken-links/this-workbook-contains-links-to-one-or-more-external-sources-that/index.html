What this message means

If you're here you've probably seen “This workbook contains links to one or more external sources that could be unsafe.”. It points at a specific problem in the file itself, not at your store or your account — which is good news, because a file problem is something you can fix and re-upload.

Why it happens

Most often this comes from how the spreadsheet was saved or edited — a stray character, a wrong delimiter, a column that got renamed or dropped, or a value in the wrong format.

How to fix it

You can hunt for it by hand, but the fastest path is to let the tool at the top of this page read the file and point straight at the offending rows or cells — then hand it to your agent to correct in one pass.

Let your agent find and repair broken links automatically

In a pipeline that hands workbooks between systems, your agent can inventory every external reference and repair the broken ones — freezing, redirecting, or fully dereferencing them — so a moved source file never silently breaks a report.

The tools this page runs

Your agent calls xlsx_external_links to inventory every reference to another workbook — its target path and whether it's absolute, a network share, or relative — then xlsx_healer_cure to rewrite or freeze the broken ones.

  • xlsx_external_links takes just the file; no options.
  • xlsx_healer_cure options: operation (e.g. make_standalone, rename_move, source_deleted_freeze) and mode (as_copy or in_place).
