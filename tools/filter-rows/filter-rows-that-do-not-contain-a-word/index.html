Let your agent filter rows for you

Describe the rows you want kept or dropped and your agent applies the filter, returning only the matching rows plus a count of what it removed.

The tools this page runs

Your agent calls xlsx_filter to keep or drop rows by a condition, and xlsx_describe to show the columns and value ranges so it knows what to filter on.

  • xlsx_describe reports each column and its value range so the filter targets the right field.
  • xlsx_filter returns only the matching rows and how many were removed.
