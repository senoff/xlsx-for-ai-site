What you upload

A Shopify products export. In your Shopify admin go to Products → Export and choose the plain CSV. This tool reads its Type column (falling back to Product Category) to learn what kinds of things you sell.

Why you map categories yourself

eBay lists every item under a numeric leaf category, and each category allows specific condition codes. There's no reliable automatic mapping from a Shopify type like "Kitchen" to eBay's category 20625 — and putting an item in the wrong category is a policy violation, not a cosmetic error. So after upload you'll see one row per product type, and you enter the eBay category ID and condition ID (for example 1000 for New) for each. Leave a type blank to skip it — those products are listed, never guessed.

The listing policies you set once

eBay needs a few facts that apply to every listing and aren't in your products: an item location, a handling time, a returns option, and a shipping type. You fill those in once and they're applied to the whole feed. Listing duration and format are optional (they default to GTC / Fixed Price).

What you get back

An eBay File Exchange Basic Template CSV — one row per published, category-mapped variant, with the Action, Category, ConditionID, price, quantity, and your policy fields filled in. In Seller Hub, upload it through File Exchange.

Your product types are read in your browser

The list of types used to build the mapping form is parsed locally, in your browser — the file is only sent to build the feed after you click the button. Your original CSV is untouched; you download a new feed file, so nothing is ever lost.
